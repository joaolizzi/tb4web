# Interface do sistema

A aplicação terá apenas uma página, com visual escuro e layout simples.

## Elementos da tela
1. Título **Calorias Diárias**.
2. Campo para escolher a data.
3. Cartão mostrando o total de calorias consumidas no dia.
4. Formulário com nome da refeição e quantidade de calorias.
5. Botão **Estimar com IA**, que sugere as calorias a partir do nome/descrição preenchido.
6. Lista das refeições cadastradas, com botão Excluir em cada item.

## Cores
- Fundo: `#080b10`.
- Cartões: `#11161e`.
- Texto: `#f4f7fb`.
- Destaques e botão principal: `#34d399`.

## Uso
A pessoa abre o site, seleciona uma data, cadastra uma refeição e vê o total atualizado. Também pode pedir uma estimativa de calorias à IA antes de salvar, conferir o valor e excluir registros. Em telas pequenas, o formulário aparece em uma coluna.

Não haverá telas de login, cadastro de usuário, metas ou relatórios.
